A third package joins the runtime and the 10.9 toolchain: **Swift Toolchain for Mavericks, for
Apple-silicon Macs** (`swift-toolchain-cross-*.pkg`). It installs the same Swift compiler, standard
library, `ld64.lld` and `clang`, built to run on an Apple-silicon Mac with macOS 11 or later, and builds
programs for OS X 10.9 by default: the same Swift source compiled by either toolchain is the same
program, byte for byte. After installing it, a new Terminal window's `swiftc-cross` (and `swiftc`, unless the
10.9 toolchain was installed there first) builds programs to copy to a Mavericks Mac that has the runtime
package. Both toolchains' `clang` now builds for 10.9 when given no flags, and links C that uses
`@available` without the `-Wl,-U,__availability_version_check` that 6.4.0-mavericks.7 needed.

The toolchain now rebuilds itself on OS X 10.9, and this release is what that rebuild produces, byte for
byte. `self-host.sh` (see DEVELOPING.md) builds the 10.9 toolchain three times over with the installed
previous release, and `self-host.sh --compare` checks the result against an installed release. To make
that possible, CI now builds the 10.9 toolchain's compiler with the cross toolchain of the same release,
and the standard library with this repo's own compiler, rather than with the swift.org compiler.

Both toolchains' `clang` now link C with their own `ld64.lld` by default. 6.4.0-mavericks.8's `clang` ran
the system linker, which on OS X 10.9 refused it (`ld: unknown option: -no_deduplicate`) unless given
`-fuse-ld=lld`.

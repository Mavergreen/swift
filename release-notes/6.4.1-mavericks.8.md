On OS X 10.9 the Swift runtime now reports the OS version through Recaulk, the family's back-fills of
newer OS APIs, linked into the runtime itself, instead of a patch of its own; nothing new needs
installing. Where macOS has `os_system_version_get_current_version` (10.12 and later), the runtime calls
the system's, as upstream Swift does.

Classes the runtime creates as it runs, such as generic classes, now get their Objective-C setup on
10.9 from Recaulk too, which fixes three things nothing in 10.9's Swift had used yet: retaining such an
object through Objective-C (`objc_retain`) no longer frees it early, a generic subclass of `NSObject`
releases its stored properties when it goes away, and a Swift Dictionary or Set passed to
Objective-C or Core Foundation (with Foundation loaded) answers `count` and the rest.

A second package joins the runtime: **Swift Toolchain for Mavericks** (`swift-toolchain-*.pkg`), a
Swift compiler, its standard library and the `ld64.lld` linker that run on OS X 10.9. Install it with
the runtime package from the same release, open a new Terminal window, and `swiftc hello.swift -o hello`
works on the Mavericks Mac itself; the first compile fetches the 10.9 SDK. Not yet: macros, Swift
Concurrency, and the Darwin/ObjectiveC overlays (`import Darwin` works through the SDK's C module).

The Swift 6.3.3 core runtime (`libswiftCore`), built from source for OS X 10.9.5 / x86_64.

- Runs real Swift on 2013-era Macs: collections, generics, class hierarchies, ARC, reflection.
- Memory-safe on real 10.9.5 (500/500 runs, Guard Malloc + MallocScribble clean).
- First release with a built-in auto-update channel (ed25519-signed Sparkle appcast).

Installs `libswiftCore.dylib` into `/usr/lib/swift`.

Requires OS X 10.9.5 or later (Intel).

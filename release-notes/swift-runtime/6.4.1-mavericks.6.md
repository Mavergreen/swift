Since 6.4.1-mavericks.5 the Swift runtime links libcxx22, the family's shared C++ runtime, instead of OS X
10.9's own libc++, so the runtime and the 10.9 toolchain need libcxx22 22.1.8-mavericks.5 or newer
installed first (https://github.com/Mavergreen/clang-22/releases/latest); their installers refuse an
older one, or none, before changing anything. 6.4.1-mavericks.5's own notes did not say so.

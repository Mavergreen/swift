The runtime now installs into its own directory, `/usr/local/mavergreen/swift-runtime/` (the
libraries in `lib/swift/`, the license in `share/doc/`), instead of `/usr/lib/swift`. An upgrade
does not remove an earlier copy from `/usr/lib/swift`.

A program built against `/usr/lib/swift` finds the runtime with an rpath of
`/usr/local/mavergreen/swift-runtime/lib/swift`: rebuild with `-no-stdlib-rpath -Xlinker -rpath
-Xlinker /usr/local/mavergreen/swift-runtime/lib/swift`, or rewrite the binary with Drydock:
`rpath replace /usr/lib/swift /usr/local/mavergreen/swift-runtime/lib/swift`.

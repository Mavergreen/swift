The runtime now builds on OS X 10.9 itself, byte for byte the same as in CI: see "Developing on OS X
10.9" in the README. To get there it is built against one pinned SDK (MacOSX11.3.sdk, fetched at build
time) instead of the CI runner's, linked by the `ld64.lld` built from the pinned LLVM source, and built
with no machine's paths left in it (llvm patch `0004` keeps the build root's path out of the builtins
archive it links). It now imports four more C++ standard-library functions, all present in 10.9's own
libc++, and it no longer carries an LLDB type summary for `ObjectIdentifier` (patch `0008`). The
toolchain package now includes clang's builtins library, where its `clang` looks for it, so C code that
uses `@available` links with that `clang` given `-Wl,-U,__availability_version_check` (a later release
makes that flag the default).

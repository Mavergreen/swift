Mavergreen swift-runtime 6.3.3-mavericks.4.

- Repackage of libswiftCore for OS X 10.9 / x86_64 from the same pinned
  swift-toolchain build environment. No source or patch change.
- The updater now trusts the Mavergreen org-wide signing key
  (/XQ+fNmP4nxdj9jnKmJDwL8rnsKYz6Kg5X61REAIqkI=). This release is signed with
  swift-runtime's previous key (G2RgxjS3...), which installed updaters trust, so
  they accept it and move to the org key; later releases are signed with that.
- Before publishing, every signing run's logs and release files are now scanned
  for any piece of the signing key, and each signature is checked against the key
  installed updaters trust.
- ACCEPTANCE IS STILL MANUAL: a macOS 26 runner cannot exercise the 10.9-only
  behaviour this runtime exists to fix. Install on real 10.9.5 before trusting it.

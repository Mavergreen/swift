Nothing you install changes: the runtime and the 10.9 toolchain's compiler, `clang`, `ld64.lld`,
standard library and builtins are 6.4.0-mavericks.10's bytes. What changed is what building them needs.
On OS X 10.9 the runtime and the toolchain now build with none of Xcode's Command Line Tools and no git:
the sources are GitHub's tarballs of the pinned commits, fetched with 10.9's own `curl` and verified by
SHA-256, and the build's checks read Mach-O files with mavericks-clang-22's `llvm-otool`, `llvm-nm`,
`llvm-lipo` and `llvm-strings`. From pkgsrc it still takes `python3` and `ninja`, until their Mavergreen
packages exist. DEVELOPING.md says what to install, and how to check, with `self-host.sh --compare` from
this release's tag, that the installed release is what its source builds on your Mac.

Built in one repo: `Mavergreen/swift` (formerly `swift-runtime`) now builds every Swift artifact for
Mavericks, from one pin. `Mavergreen/swift-toolchain`, which supplied the LLVM build support and the
swift.org compiler this runtime is built with, was merged in and archived. The runtime itself is
unchanged: same Swift, same patches, same install location. The ingredient list below shows the pins
and patches as added because they moved into `pins.env` and `patches/runtime/`; none of them changed.
The updater now reads its feed from `Mavergreen/swift`; GitHub forwards the old address, which is how
an installed updater found this release.

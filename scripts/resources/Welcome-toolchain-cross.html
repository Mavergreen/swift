This installs a Swift toolchain for Apple-silicon Macs that builds programs for OS X 10.9 — swiftc, the Swift standard library for 10.9, the ld64.lld linker and a matching clang, built from swiftlang/swift source — into /usr/local/mavergreen/swift-toolchain-cross/. New Terminal windows find swiftc-cross on their PATH, and swiftc as well unless the 10.9 toolchain package is installed here too and was installed first.

What it builds runs on a 10.9 Mac with the Mavericks Swift Runtime package from the same release. The first compile fetches the Mac OS X 10.9 SDK into ~/Library/Caches/mavericks-sdk.

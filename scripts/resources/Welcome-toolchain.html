This installs a Swift toolchain that runs on OS X 10.9 — swiftc, the Swift standard library, the ld64.lld linker and a matching clang, built from swiftlang/swift source — into /usr/local/mavergreen/swift-toolchain/. New Terminal windows find swiftc on their PATH.

Programs it builds need the Mavericks Swift Runtime package from the same release. The first compile fetches the Mac OS X 10.9 SDK into ~/Library/Caches/mavericks-sdk.
